# CZ-1's pops (docs/CZ1.md "Pops", tools/emu/test_cr.sh): the chord part on CZ-1 05 STRINGS 2 (Casio's A-5: both lines),
# the bass part on CZ-1 13 SYNTH.BASS (B-5: a DCW attack of a fifth of its range a block), as perf_g.txt sets them.
# A 6-note chord on D4 from 3240 ms, held 1.2 s; the same chord struck again three times 20 ms after its release
# (every voice still sounds: the same notes on their own voices); two chord changes with common tones in one frame
# (D4 -> A4 -> D4); released. Until 0.19 each of these cut the DCA of the sounding voices to 0 in one sample and
# stepped the wave with the DCW depth at a block's edge.
wait 300
btn ENV down                  # the bass part's engine (docs/PRESETS.md: BASS held + EDIT, the editor's EDIT-held picker):
wait 50
btn EDIT                      # BASS held + EDIT: the bass sound's editor
btn ENV up
wait 300
btn EDIT 600                  # EDIT held: the engine picker (the bass part)
wait 200
knob SELECT +1                # VA (the bass part's default) -> CZ-1
wait 200
btn OCT+                      # kept
wait 200
btn EDIT                      # the editor closed
wait 200
btn GLO down
wait 100
knob PRESETS +3               # OPT + PRESETS: the chord part to the CZ-1 (01 BRASS 1), on OPT's release
wait 100
btn GLO up
wait 50
knob PRESETS +4               # CZ-1 05 STRINGS 2
wait 300
knob ALGORITHM +14            # OFF -> CZ-1 13 SYNTH.BASS
wait 300
dump
