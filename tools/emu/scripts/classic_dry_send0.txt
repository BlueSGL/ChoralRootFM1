# ChoralRoot 0.19: Classic is 0.18's sound bit for bit where no part sends into the chorus (tools/emu/classic_exact.sh,
# its second part: this script through 0.18's emulator and through this tree's held at Classic, the stereo chorus as
# the unit has it; docs/AUDIO-QUALITY.md "Classic is 0.18's"). The delay and the reverb stay as they are.
# FX held: the layer opens on Sends (0.18's first page: Drive / Chorus / Delay / Reverb on KNOB 1..4); KNOB 2 -8: the
# chord part's chorus send from 45 to 0 (6 a detent); FX let go, OCT- closes the layer. The bass on (ALGORITHM +18:
# DEEP SUB, whose chorus send is 0), MASTER at its top, a 4-note chord with the bass held 3 s, its tail.
# Only commands and controls 0.18 has: the same file runs in both emulators.
master 1023
wait 300
btn FX down
wait 500
knob KNOB2 -8
wait 300
btn FX up
wait 300
btn OCT-
wait 300
knob ALGORITHM +18            # the bass on
wait 700
key F3 down
key 2 down
key 4 down
key 5 down
wait 40
btn D4 down
wait 3000
dump
btn D4 up
key F3 up
key 2 up
key 4 up
key 5 up
wait 2500
quit
