## Merged after 0.22-beta3

- **The loop editor previews a step.** With the loop stopped, turning PRESETS onto a step plays it as the loop would
  (its length, its voicing, its ratchet); an empty step is silence; while the loop plays you hear the loop. Nothing is
  recorded by it. Asked for in GitHub issue 8.
