ChoralRoot 0.22 (in progress)

- **Chord numerals in Key Mode.** A new setting, **Numerals**, on the KEY layer's second page (hold KEY, turn SELECT,
  KNOB 4). It is off until you turn it on. With Key Mode on, the top line then shows the Roman numeral of the chord
  you are playing beside the key: in C major `Key: C · I` for C, `Key: C · V` for G, `Key: C · vi` for Am. Capitals
  are chords with a major third, small letters chords with a minor third. Hold SAVE to keep the setting. Nothing
  you hear changes.

## Going back to 0.21

0.21 and the versions before it have no Numerals setting and ignore it; nothing else is lost or reset. If you hold
SAVE while on the older version, Numerals is off when you come back to 0.22.
