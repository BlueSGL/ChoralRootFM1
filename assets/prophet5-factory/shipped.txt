# P5's shipped factory programs (docs/PROPHET.md "The shipped list"; tools/gen_prophet_factory.py reads this file).

# One Sequential program number (1..200, the program's place in prophet5-v1.03.syx) a line, in the order of the
# pool: the first line is PRESETS 01. "#" starts a comment. The word "all" alone on a line: every program not named
# yet, in the bank's order (a file with only "all", or no file: the 200). INIT alone: FELUCCA_P5_FACTORY=0.
# A program's number is its identity: it stays the same wherever the program stands in this list, and it is what the
# session keeps (the program's own bytes), so a list changed in a later build does not change a saved sound.
# All 200 with their numbers: python3 tools/gen_prophet_factory.py --list all
#
# After a change: ./build.sh (or any build: the header is generated again), then the P5 goldens alone:
#   GOLDEN_UPDATE=1 BUDGET_UPDATE=1 sh tests/run_tests.sh      (docs/PROPHET.md "The shipped list" has the steps)
